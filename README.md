# 成品油销量驾驶舱

陕西高速延长 · 服务区加油站成品油销量在线看板。

- 在线地址：<https://lvritiann.github.io/youpin-sales-cockpit/>
- 形态：单文件静态页（`index.html`，数据在构建阶段注入，运行时零请求、零依赖）
- 配套：`brand.png`（页头标识）、`.nojekyll`（跳过 Jekyll，保证静态资源原样发布）

## 看板内容

| 模块 | 口径 |
|---|---|
| 累计 KPI | 全口径 = 零售 + 小额配送；仅零售 = 不含小额 |
| 本月信息带 | 随口径开关切换，天数取该会计月已填天数 |
| 近 30 天日销 | 按日柱按当前口径重算，柱高之和恒等于跨度合计 |
| 会计月轨迹 | 堆叠柱：柴油 / 汽油 / 小额三段，悬停出总量与各段吨数、占比 |
| 站点排行 | 恒 15 对实体站，小额配送是公司级虚拟实体，不进榜 |
| 路段结构 | 8 条高速路段按 15 对归集，可切全年或单个会计月 |
| 明细表 / 年度表 | 全口径 16 行（含小额）；仅零售 15 行 |

## 两个必读口径

1. **会计月 = 每月 26 日 → 次月 25 日**。源文件名里的月份是「止月」，`202608` 指 7/26–8/25，不是 8 月自然月。
2. **小额配送是第 16 个「公司级」实体**，没有站点、没有路段、没有渠道拆分。只有在「全口径」下才出现；切到「仅零售」它会在排行、明细、轨迹里同时消失——这是设计如此，不是数据丢失。

## 数据更新

页面本身不含取数逻辑，数据在构建阶段写进 `index.html`。更新流程：

```bash
cd _kdocs
python build_cockpit2.py        # 由 data.json / _archive 重新生成 cockpit/index.html
cp ../cockpit/index.html <本仓库>/index.html
```

改完推送本仓库，GitHub Pages 约 30–60 秒后自动生效。
